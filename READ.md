# 🕌 Run to Istanbul — Travel Guide

> A comprehensive travel guide for Istanbul, built as a personal project to help NYUAD students and travelers make the most of their trip.  
> 🌐 **Live site:** [pedrolfelix.github.io/RuntoIstanbul.github.io](https://pedrolfelix.github.io/RuntoIstanbul.github.io/)

---

## 📖 About

**Run to Istanbul** is a fully hand-coded travel guide website covering everything a first-time visitor needs to know about Istanbul — from food and culture to budget tips, transport, and nightlife. Originally created for NYUAD students planning their semester or holiday break, but useful for any traveler.

---

## 🗺️ What's Inside

| Section | Description |
|---------|-------------|
| 🏛️ **Why Istanbul** | Culture, history, landscape, food, coffee & tea culture |
| 🌸 **Spring or Fall** | Season-specific weather, clothing tips, and activities |
| 💰 **Dealing with Money** | Currency exchange, Wise/Revolut tips, bargaining guide with Turkish phrases |
| ✈️ **Cheap Flights & Stay** | Budget airlines, Airbnb vs hostels, airport transport |
| 🗓️ **3-Day Trip Guides** | Curated itineraries for cultural, culinary, adventure, and mixed tourism |
| 📍 **Recommendations** | Curated Google Maps with top restaurants, cafes, and spots |
| 🍺 **Easter Egg** | Nightlife guide for bars and clubs (18+) across Beyoğlu, Kadıköy, Ortaköy & Galata |

## ✨ Features

- Responsive design for mobile and desktop
- Embedded Google Maps with personal recommendations
- 3-day curated itineraries for different travel styles
- Bargaining guide with audio pronunciations of Turkish phrases
- Easter egg hidden section for nightlife recommendations

## 🚀 Running Locally

```bash
git clone https://github.com/Pedrolfelix/RuntoIstanbul.github.io.git

# Just open the index.html in your browser — no build step needed
open index.html
```
